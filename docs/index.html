Funciones

Respaldá, migrá y restaurá desde un mismo lugar.

Dos flujos de trabajo para cubrir las tareas más habituales con correo IMAP.

01

Respaldar / Exportar

Descargá tus cuentas y mantené una copia local de tus mensajes.

  • Agregar, editar y eliminar cuentas
  • Configuración TOML o JSON
  • Destino de almacenamiento configurable
  • Concurrencia configurable
  • ZIP por cuenta o consolidado
  • Sincronización incremental
  • Limpieza automática
  • Logs y progreso en tiempo real
02

Restaurar / Importar

Recuperá una copia completa directamente sobre un servidor IMAP.

  • Importación desde ZIP o carpeta
  • Detección de correos y carpetas
  • Creación automática de carpetas
  • Inyección masiva mediante APPEND
  • Transferencia directa vía TLS
  • Respeta fechas y metadatos
  • Procesamiento concurrente
  • Sin depender de los límites del webmail
Cómo funciona

Del servidor a tu backup en pocos pasos.

1

Configurá

Agregá tus cuentas IMAP y elegí dónde guardar el backup.

2

Respaldá

IMAP Backup descarga los mensajes y conserva su estructura.

3

Guardá

Tus correos quedan almacenados localmente como archivos .eml.

4

Restaurá

Volvé a subirlos a un servidor IMAP cuando sea necesario.

Tecnología

Nativo. Ligero. Sin Electron.

IMAP Backup está desarrollado en Rust utilizando egui y eframe. Las tareas de red y procesamiento se ejecutan en segundo plano para mantener una interfaz fluida.

🦀 Rust Código nativo de alto rendimiento.
⚡ Bajo consumo Diseñado para utilizar pocos recursos.
🖥️ Sin WebView Sin Electron ni Tauri.
🔄 Procesamiento asíncrono Las operaciones no bloquean la interfaz.
📦 Portable Un ejecutable listo para utilizar.
🐧 Windows + Linux Soporte para los principales sistemas de escritorio.
