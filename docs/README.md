# IMAP Backup — GitHub Pages

Esta carpeta contiene únicamente la landing page de IMAP Backup.

## Estructura

- `index.html` — estructura de la página.
- `style.css` — estilos y diseño responsive.
- `script.js` — JavaScript mínimo para navegación suave.
- `img/icon.png` — icono del proyecto utilizado como favicon.

## Publicación

En GitHub:

**Settings → Pages → Build and deployment**

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/docs`

Luego la página estará disponible en:

`https://estebanchavez27.github.io/imap-backup/`
